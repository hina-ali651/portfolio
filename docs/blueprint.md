# **App Name**: Hina Ali - Automation Architect

## Core Features:

- Hero Section with Premium Animation: Display a full-screen hero section with Hina Ali's name and tagline, set against a subtly animated premium background. Includes a 'Hire Me' CTA button that stands out through high contrast.
- AI-Powered Style Check: LLM powered 'style tool' analyzes website's content against defined parameters to suggest any changes which may improve website premium presentation style, color and wording usage to communicate expertise.
- Services Showcase: Showcase Hina Ali's services using luxury-styled cards, each featuring relevant icons. Includes sections for API Integration, LLM Integration, Webhooks, AI Agents, MCP setups, and Business Automations.
- Portfolio/Case Studies Gallery: Display portfolio projects with large, high-quality screenshots and/or videos. Implement smooth hover effects to enhance user interaction.
- About Me Section: Modern card-style 'About Me' section to introduce Hina Ali, highlighting her expertise in n8n automation, API integrations, and AI agent development.
- Dynamic Testimonials: Showcase testimonials in a visually appealing slider/carousel format to build trust and credibility. This section is designed to dynamically update as testimonials become available.
- Contact Form with Modal: Implement an elegant contact form accessible via a modal, allowing visitors to directly reach out to Hina Ali. This could either be a Typeform integration or a custom email form.

## Style Guidelines:

- Primary color: Deep navy (#191970) to establish a professional and trustworthy base.
- Background color: Near-black (#0A0A0A) to enhance the premium feel and ensure contrast with lighter elements.
- Accent color: Emerald green (#50C878) for interactive elements and highlights, giving a luxurious and vibrant touch.
- Font: 'Poppins', a geometric sans-serif, to create a precise, contemporary and fashionable look for headlines and body text. Note: currently only Google Fonts are supported.
- Implement a dark mode-first design that is responsive and mobile-friendly, ensuring optimal viewing experience across all devices.
- Employ subtle micro-animations and hover effects to enhance user engagement and create a smooth, modern experience.
- Apply glassmorphism and smooth shadows to UI elements, providing depth and a tactile feel. Use gradients to subtly enhance visual appeal and modernity.
